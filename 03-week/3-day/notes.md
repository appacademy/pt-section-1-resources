# Data Types in JS: Primatives vs References

- 2 main categories of data types in JavaScript: `Primative` and `Reference`

Five Primitive Types (that we've seen):

- Boolean - true and false
- Null - represents the intentional absence of value.
- Undefined - default return value for many things in JavaScript.
- Number - like the numbers we usually use (15, 4, 42)
- String - ordered collection of characters ('apple')

One Reference Type:

- Object - (an array is also a kind of object)!

Big Difference: `Primitive` types are immutable. Meaning they cannot change. `Reference` types are mutable.
